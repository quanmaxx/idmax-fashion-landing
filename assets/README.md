# Assets

Toàn bộ ảnh của landing page nằm trong "images/". Nội dung gallery của dự án nằm trong "data/projects.js"; JavaScript chỉ đọc dữ liệu từ file này.

Khi thay ảnh, ưu tiên:

- JPG hoặc WebP cho ảnh nền và ảnh thời trang.
- Kích thước cạnh dài khoảng 1400–2400px.
- Nén ảnh trước khi đưa lên web để trang tải nhanh hơn.
