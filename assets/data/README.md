# Dữ liệu

"projects.js" là nơi quản lý nội dung của 6 dự án và đường dẫn ảnh gallery. File được nạp trước "js/main.js" trong "index.html".

Mỗi dự án gồm:

~~~js
{
  title: "Tên dự án",
  category: "Phân loại",
  description: "Mô tả",
  highlights: ["Điểm 1", "Điểm 2"],
  quote: "Phản hồi hoặc câu kết",
  images: ["assets/images/projects/.../gallery-01.jpg"]
}
~~~
