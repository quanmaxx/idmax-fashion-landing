# Thư viện hình ảnh

Các ảnh đang được dùng trực tiếp trong file HTML mới nhất đã được gom thành file cục bộ để dễ thay thế trong VS Code.

- "backgrounds/": ảnh nền theo section.
- "projects/<ten-du-an>/": ảnh card và ảnh gallery riêng từng dự án.

Không đổi tên thư mục dự án nếu chưa cập nhật lại đường dẫn trong "index.html" và "assets/data/projects.js".
